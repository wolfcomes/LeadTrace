# 按风险查阅的质量问题

本文件补充 [科学提取指南](extraction-guide.md)，供遇到对应风险时查阅，不要求每个阶段重复阅读。历史论文编号不作为新论文答案或硬编码分组模板。

| 触发风险 | 必须采取的检查 |
|---|---|
| Activity 数量下降、表格缺行/列/物种 | 回到源 measurement inventory，逐表列 expected/extracted/unresolved/not_applicable；未知分母不从候选推算，未测/ND 和漏提分开 |
| 值相同但误差/条件未查 | 核对原单元格、完整表头、SD/SEM/n、浓度/温度/时间/物种；value-only 不计整行正确 |
| 给药剂量单列 Activity | 判断是否条件，保留真正的 ED50/MTD 等终点；修正时核查剂量仍留在相应实验条件 |
| 泛式、开放 linker 与完整中间体混在清单 | 泛式/开放片段明确不适用；可界定编号中间体即使无活性也 required；完整身份未解析不删分母、不造占位结构 |
| R/S 标签不同而结构相同 | 源明确的立体信息须编码并核对；若源未给绝对构型则不猜，constitution-only 不算立体已确认 |
| 可解析/分子式正确，但共核连接或稠合错误 | 从源独立确定原子/键和稠合参考，重新读取最终结构重绘并映射所有变体；修一个代表不算修全族，不用通用环大小禁令 |
| 已有 locator 但图不完整 | 看实际裁图及每个 compound 自身的完整集合，尤其表首末行、R 基定义、OH/电荷/脚注；共享区域不增加独立结构检查数 |
| 共用反应物把很多系列连成一团 | 连通不等于同一优化家族；保持真实多底物关系与跨组身份，按路线含义分组，不删正确边求布局 |
| 删除错边后孤点/角色残留 | 复核成员、逐组图角色、两类型参与原因；不恢复被否决关系，也不删除合法 Compound |
| 合成成员大量 unspecified，但程序无 role conflict | 程序只发现显式角色冲突；逐组核对局部位置与未决原因，零冲突不等于角色完整 |
| collective 编号映射未决，却给每个编号填了具体结构 | 回查共核、R 基及反应依据；有依据的完整推导可带 review_hint，仅编号猜测仍不收录，保留 inventory required/观察与待协调差异 |
| 已有边/Activity 全部 correct，但依赖有错误结构/漏步骤/错误裁图 | 分开数值、标签配对与全字段判定；传播身份依赖错误并核对摘要，正确数值不因此变成数值抄错 |
| 声称修复的条数多于实际字段差异 | 逐反馈核对父/最终值与源依据，明细重算；Activity 用测量 tuple＋来源匹配，不靠 compound 汇总或行号猜 |
| 修补新增 Compound，却沿用旧测量/参与覆盖 | 扩查新增身份的观察、定位和双类型关系；旧记录无损不等于新增范围完整 |
| 所有 SAR 叶节点被称为 lead | 分开图位置、比较 baseline、论文优选；优选须源支持，可有多个或未知 |
| 研究起点/论文优选沿用首编号、首表行、最后产物或单项最强活性 | 回到 Abstract/Introduction/Results/Conclusion 建立 role matrix；逐一记录作者明确点名的全部分子、scope 和选择语句。多起点/多优选分别建 highlight，不能压成一个 |
| Compound 角色正确但 Evidence 只证明存在、合成、单项活性、PK 或体内出现 | 将其分类为 `evidence_linkage_error`，保留 Compound/role，换成明确支持角色身份的正文、摘要、图题或结论 Evidence |
| 一篇文章有文献 hit、内部 lead 和后续候选，却只保留一条 article-level highlight | 分开 `study_start` 与 `paper_selected` 的 scope；内部 lead、文献起点和并列候选分别记录，找不到明确选择时保持 unresolved |
| 文章写的是多个并列 candidate，却把某一个最强 assay 分子当唯一终点 | 核对作者的 selection/advanced/developed/lead wording 和后续 panel；保留全部被明确推进的分子，单项 assay 不足以构成 paper_selected |
| 审查 expected 与 candidate 冲突 | 双方都可能错，回源放大核对；不要盲改候选。审查内部矛盾先修正审查，保留原记录 |
| 审查称 raw token/条件缺失，或把统计歧义计为数值抄错 | 先查最终字段/context 的实际内容，再评语义；值、统计/条件和来源分开判定，保留源措辞与未决 |
| 局部任务需要重复读大量旧报告 | 生成结构化 handoff、冻结变更与依赖，复用有效证据；完整历史为后备，不将裁图修补升级为全篇重复提取 |
| 预算末尾没有落盘 | 每表/系列/审查项及时保存；无新证据的冲突不无限重试；实际时间不足与主动省略明确区分 |

实际质量和效率分别量化：同口径独立审查的 C/E/U、覆盖和交付后缺陷，以及全部调用/失败/返工的费用与耗时。缺失 usage/cost 为 null；token 便宜、文件变短或进程正常结束不证明整体降本或正确率提高。
